# Rana Ibrahim — Portfolio

A responsive single-page portfolio built with plain HTML and CSS.

## Publish with GitHub Pages
1. Create a **public** repository named `ranaibrahim3103-droid.github.io` (use your exact GitHub username).
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. Wait for deployment and open `https://ranaibrahim3103-droid.github.io`.

Review the project links and details before submitting. The House Price and Flower Shop cards currently link to the GitHub profile because their specific repository URLs were not available when this draft was prepared.
